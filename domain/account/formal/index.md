# Formal Verification

Dafny sources that implement the formal laws of the Account domain.

---

## Sources

| Module | Description |
|--------|-------------|
| `foundation/` | Domain primitives: Capability, Identity, Scope, Restriction, Subject. |
| `authority/` | Credential, Credential Authority, Session, Delegation, Effective Authority. |
| `authorization/` | Authorization, Authorization Validation, Replay. |
| `account/` | Account, Account Transitions. |
| `policy/` | Policy, Policy Effect, Policy Consumption. |
| `execution/` | Domain Action, Execution Request, Execution Context, Execution Constraints. |
| `laws/` | Formal laws (`D1`–`D6`) encoded as lemmas. |
| `proofs/` | Proofs derived from the laws. |

---

## Verification Status

Verification status is generated by the build pipeline and exposed as:

- `dist/_data/verification.json` (machine-readable).
- A rendered badge per document (human-readable).

See `guides/build-pipeline.md`.

---

## Running

```bash
docs verify
```

Runs the Dafny verifier against the sources. Optional during `docs build`.
