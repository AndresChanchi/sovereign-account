# kipio_account_generated

Dafny-generated Kipio Account domain model.

This crate contains a single file, `kipio_account_all.rs`, produced by the
Dafny 4.11 Rust backend from the Kipio Account formal specification. It is
the compiled representation of the domain's value objects, datatypes,
predicates, and injects.

It is not intended to be edited by hand. The source of truth is the Dafny
tree; the Rust is regenerated by [tools/export_rust_production.py](https://github.com/AndresChanchi/vaultchain-sovereign-agent/tree/develop/domain/account/formal).

## Contents

The generated module declares the domain's entities and value objects as
Rust datatypes, plus the executable counterparts of the ghost relations
that the Dafny injects introduce:

- **Entities** — `Account`, `Identity`, `Credential`, `Session`,
  `Delegation`.
- **Value objects** — `Capability`, `Restriction`, `Scope`, `Subject`,
  `Authorization`, `PolicyEffect`, `ExecutionContext`, among others.
- **Compositions** — `AuthorizationCanBeAcceptedFull`,
  `ComputeEffectiveAuthorityWitness`, `ApplyPolicyConsumption`,
  `ValidExecutionContextForAccountFull`.

## Usage

```toml
[dependencies]
kipio_account_generated = "0.1.0"
```

The crate re-exports the runtime under its canonical name, so consuming
code can refer to `dafny_runtime::...` directly.

## Origin

Produced by `tools/export_rust_production.py`, which:

1. Copies the runtime `.dfy` tree into `generated/dfy-annotated/`.
2. Injects the composition sources from `tools/dafny_inject/`.
3. Annotates the five abstract types with `{:extern}`.
4. Translates the synthesized aggregator in a single Dafny invocation.
5. Fixes the Dafny 4.11 trait-object return-type quirk.
6. Injects the five extern Rust types into their modules.

The output of every step is reproducible. Any change to the Dafny source
requires re-running the exporter; the crate is not edited directly.
